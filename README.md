# One Emoji, One Smile

This entry writes exactly one emoji to `entry.txt` and nothing else — a single hugging face, no trailing newline, no extra text, no decoration. The smallest possible smile, delivered as-is.

```
🤗
```

## How it works

Run the program with the output directory set via `MAKEFUN_OUTPUT_DIR`:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

It creates the output directory if needed and writes the single emoji 🤗 to `entry.txt` inside it.
